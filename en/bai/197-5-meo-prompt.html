Five tips to remember

After almost two hundred videos, if you remember only five prompt tips, the instructions you send to AI, remember these.

TIPS 1-2

Examples and a role

One: give a few examples for AI to copy, called few-shot. Two: give AI a role, like a strict editor.

TIPS 3-4

Step by step, set a format

Three: ask AI to think step by step before concluding. Four: set the answer format, like a three-column table.

TIP 5

Break big tasks down

Five: break big tasks into small steps instead of stuffing everything into one long instruction.

Try it now

Upgrade an old prompt

Take a prompt you use often, add one example and an answer format, then compare with the old result.
