Air conditioner showing an error code? How a repair tech asks AI

An air conditioner shows a strange error code? A repair tech can take a photo and ask AI right at the customer's home.

Watch videoVideo in Vietnamese

An air conditioner error code

An air conditioner blinks a strange error code, and the repair tech can take a photo and ask AI right at the customer's home.

ERROR CODE

Look up the code for that exact model

Send AI a photo of the error code with the brand and model, and ask it to list the common causes, from easiest to hardest to check.

CHECK

Check against the manual

AI can mix up different models, so always check the manufacturer's manual before replacing parts.

EXPLAINING

Explain it to the customer

Ask AI to write a simple explanation for the customer: what's broken, why it needs replacing and what it costs, so they understand and trust you.

Try it now

Next time you see a strange code

Next time you see an unfamiliar error code, send a photo to a chatbot with the brand and model, then compare its list of causes with the manual.
