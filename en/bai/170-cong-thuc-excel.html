Excel formulas in plain words

You don't need to memorize Excel or Google Sheets formulas. Describe what you want to calculate and AI will write the formula.

BE CLEAR

Name the columns and rows

Say which column the data is in, which row it starts on and what result you need, for example total revenue by month.

TEST THREE ROWS

Check on three rows

Before using it on the whole sheet, test it on three rows where you already know the answer. Use it only if all three match.

EXPLAIN

Ask AI to explain it

Ask AI to explain each part of the formula, so you can fix it yourself next time the sheet changes.

Try it now

A calculation you do by hand

Describe a calculation you usually do by hand, then test the formula AI writes on three rows you know.
