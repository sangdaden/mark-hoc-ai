What is a prompt template? Build your own set of prompt templates

Retyping the same long prompt every week, and always forgetting something? The last part puts every trick into one template.

Follow on YouTubeComing soonVideo in Vietnamese

Retyping from scratch every time

Every week Mark retypes the same long prompt to write a report, and every time he forgets something.

PROMPT TEMPLATE

One template, used forever

Bit says: make a prompt template, a template with blanks. Combine the tricks from this series: role, examples, step by step, output format and self-critique.

EXAMPLE

A weekly report template

For example, a weekly report template: you are the assistant to a sales team lead. This week's numbers: paste here. Answer with three bullet points and one action for next week.

WHERE TO KEEP IT

Somewhere easy to grab

Keep the template somewhere easy to grab: a notes file, a Project, or turn it into a Skill, as in videos 28, 66 and 67.

IMPROVING

Fix the template after each use

Whenever AI's result isn't quite right, don't just fix the answer. Fix the template too, so the same mistake doesn't happen again.

RECAP

Six tricks from the series

In short, six tricks: few-shot, role, chain of thought, output format, prompt chaining and self-critique.

Try it now

Write your first template

Pick the task you ask AI for most, write it as a template with blanks, and use it all this week.
