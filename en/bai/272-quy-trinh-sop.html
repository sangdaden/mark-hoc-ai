Write an SOP for new employees with AI

Write an SOP for new employees with AI, so newcomers don't have to ask about the same task again and again.

Watch videoVideo in Vietnamese

New hires ask the same thing

New hires keep asking about the same task because the process only exists in the veterans' heads.

SOP

What a process is

An SOP, a standard operating procedure, is a step-by-step list so anyone who follows it gets the same result.

ASK AI

Messy is fine

Just describe how you do it, even in a messy way. Ask a chatbot to arrange it into numbered steps, each starting with a verb.

TEST RUN

Let a new hire try it

Give the draft to a new hire to try. Wherever they hesitate, add a screenshot or a note.

Try it now

One task in five steps

Pick a task you do every week, describe it to AI and ask it to write it as five steps.
