Copy over, paste back

Copy from a web page, paste into the chat, then copy the result and paste it into Excel. Now Claude can go straight into those tools.

CHROME

Claude in a browser side panel

Claude in Chrome is an extension that opens in a side panel next to your browser. It reads the page you're on, clicks buttons and moves between pages for you.

Example: compare three stores

For example: open three pages selling the same item, and ask it to compare price, shipping fees and warranty length.

Payment step: do it yourself

Because Claude clicks for you on the web, use it on sites you trust, and do the payment step yourself.

EXCEL · POWERPOINT

Analyze, then build the slides

For Excel and PowerPoint, install the Claude add-in from Microsoft Marketplace. It analyzes the numbers in Excel, then builds slides showing the results in PowerPoint, with no copying back and forth.

Which plan?

All three need a paid plan, Pro and up.
