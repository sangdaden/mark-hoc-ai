Don't let an AI agent pay, send emails or delete data on its own

AI agents work fast, so their mistakes happen fast too. Three things never to let an agent do alone: pay, send messages, delete data.

Fast mistakes

Agents work fast, so when they're wrong, they're wrong fast too. Three things never to let one do alone: pay, send messages, delete data.

MONEY

No paying on its own

Don't save bank cards in an account the agent uses. At checkout, you check and click yourself.

SENDING

Drafts only

For emails and messages, the agent may only write drafts. You read them, then click send yourself.

DELETING

No deleting on its own

To clean up files, let the agent only list what should be deleted. You press delete.

Try it now

Three guardrail lines

Write three guardrail lines about money, messages and deleting, and paste them at the top of every agent brief.
