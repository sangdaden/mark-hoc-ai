Asking the wrong things

Asking about dating or hometowns in an interview is both useless and unfair. Ask about the job.

SITUATIONS

Ask with real situations

Good questions use real shop situations, like asking how they'd handle a customer complaining the food is cold.

TRIAL TASK

Let them try a task

For hands-on jobs, a fifteen-minute trial, like packing an order or making a drink, often shows more than a whole conversation.

SAME SET

Ask everyone the same

Ask a chatbot for five questions based on the criteria from the last part, then ask every candidate the same set to be fair.
