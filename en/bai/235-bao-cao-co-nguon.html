Video #235 · Delegating to AI agents · Part 3/5

Have an AI agent research and write a report with sources

Ask AI to research and write a sourced report: agent reports look very professional, but don't trust any sentence without a source.

Watch videoVideo in Vietnamese

Polished but unsourced

A report written by an agent looks very professional, but any sentence without a source shouldn't be trusted yet.

NARROW

Narrow the topic

First, narrow the topic, for example the cost of charging an electric scooter at home for one month.

SOURCES

A source after every point

Tell the agent to put a source after every point, prefer official sites, and say clearly which points have no source.

CHECK

Open three sources

When you're done reading, open three sources and see if each page says what the report claims. One error means re-checking the whole thing.

Try it now

Five points with sources

Ask a chatbot to research a small topic, request five points with sources, then open and check two of them.
