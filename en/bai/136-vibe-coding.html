What is vibe coding? Building apps without knowing code

What is vibe coding? A way to build an app without knowing code: you describe it in words, AI writes the code and shows the app for you to try.

Watch videoVideo in Vietnamese

Apps without code

You can build a small app just for you without knowing how to write a single line of code.

VIBE CODING

Say it in words, AI writes the code

This is called vibe coding. You describe it in words, AI writes the code, then shows the app right away for you to try.

THE LOOP

Try, give feedback, fix

If something isn't right, just keep talking, like make the button bigger or change it to blue, and AI fixes it in seconds.

TOOLS

Where to do it

Many chatbots like Claude or ChatGPT already have an app preview right inside the chat, nothing extra to install.

Try it now

Your first countdown app

Ask a chatbot to make a page that counts down to your birthday, then ask it to add fireworks when the clock hits zero.
