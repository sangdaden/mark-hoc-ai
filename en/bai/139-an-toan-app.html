Building apps with AI: don't leak your passwords and API keys

Building apps with AI is handy, until you paste a real password into the code. What to be careful about.

Watch videoVideo in Vietnamese

A password in the code

Your homemade app is really handy, until you paste a real password into the code.

PASSWORDS

Don't expose secret keys

If a password, API key or bank code sits in the code, anyone who can see the app can take it. Keep them somewhere private.

DATA

Customer data needs an expert

If the app stores customers' phone numbers or takes payments, have someone who knows security review it before letting others use it.

BEST FIT

Best for your own tasks

Vibe coding works best for tools just for you, like a timesheet, a cost calculator, or a learning game for your kids.
