What is synthetic data? When AI makes data to teach AI

AI will soon have read all the text on the internet, so where will it get more data? Bit explains.

Follow on YouTubeComing soonVideo in Vietnamese

Running out of data?

Mark hears that AI will soon have read all the text on the internet, and wants to know where it will get more data to learn from.

SYNTHETIC DATA

Data made by AI

Bit explains: one way is synthetic data, data made by AI itself. For example, AI writes millions of math problems with solutions.

FILTERING

Check before using

The key step is careful filtering: recheck the math, run the code, and only keep what's correct.

WHAT IT'S GOOD FOR

Filling gaps where data is rare

It's useful where real data is rare or sensitive: unusual situations, or made-up records so real people's information isn't exposed.

RISKS

A photocopy of a photocopy

The risk: if AI only learns from AI, over time it's like a photocopy of a photocopy, getting blurrier. This is called model collapse, so real data always has to be mixed in.

REMEMBER

When you see this word

When you see this word, think: data AI makes to teach AI, useful when it's filtered carefully.

Try it now

Do it today

Ask AI to write 5 math problems with solutions, then work each one out yourself. You'll see why the filtering step matters.
