What does Claude remember about you? Projects and Memory in Claude

Every new chat, you have to explain again: "I teach 8th grade, keep it short"?

Watch videoVideo in Vietnamese

Explaining from scratch every time

Every new chat, you have to explain everything from scratch? Claude has two places that help it remember: Projects and Memory.

PROJECT

A workroom for one task

A Project is a private workroom for one task. You upload documents and set instructions once, and every chat inside shares them.

Each room has its own memory

The free plan lets you create five Projects. Each Project also has its own memory, so class stuff doesn't mix with family stuff.

MEMORY

Settings, Memory

Outside Projects, Claude remembers general things about you on its own: your job, how you like answers. Go to Settings, then Memory, to view, edit or delete each line.

Pause, wipe, incognito

You can pause memory or wipe it completely. For private matters, open an incognito chat: no history saved, nothing goes into memory.

Try it now

See what Claude remembers about you

Open Settings, then Memory, and read what Claude remembers about you. If a line is wrong, edit it or delete it.
