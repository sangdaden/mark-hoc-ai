CLAUDE CODE

Tả bằng lời, nó viết và chạy

Claude Code là một coding agent, tức trợ lý lập trình. Bạn tả việc bằng lời thường, nó tự viết code, chạy thử, gặp bug thì tự sửa.

Không cần màn hình đen

Nó có trong ứng dụng máy tính và trên web, không bắt buộc dùng terminal, màn hình đen của dân lập trình.

Người không chuyên làm gì?

Người không chuyên dùng nó để làm công cụ nhỏ: đổi tên ảnh hàng loạt, gộp 12 file Excel thành một, hay dựng trang web đơn giản cho tiệm.

Thử trên bản sao trước

Nhớ quy tắc: thử trên bản sao vài tệp trước, đúng rồi mới chạy cho tất cả. Claude Code cũng hỏi bạn trước khi sửa hay xóa tệp.

Gói nào?

Claude Code cần gói trả phí, từ Pro trở lên.
